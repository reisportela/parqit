### 2.2 — S1 — `relaxed` union with differing schemas still loads `NUEMP_1` and drops its metadata silently (A2-2 residual; help claims it works)
Repro: `new/N7_names.do` (`nm/rel/a.parquet` = `nuemp NUEMP s` with a parqit manifest + `nm/rel/b.parquet` = `nuemp NUEMP s extra`): `parqit use using "nm/rel/*.parquet", clear relaxed` → `nuemp NUEMP_1 s extra`; `nm/rel2` (clash only in the 2nd file) → `nuemp s NUEMP_1`.
